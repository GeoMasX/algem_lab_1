# algem_lab_1

На доп балл сделана реализация FloodFill8 и код написан на C. Позже будет переписан на C++ для выполнения последующих работ.

# Постановка задачи

Реализовать консольное приложение на языке C — простой графический редактор, который работает с экраном как с двумерным массивом пикселей.

Требуется:

- хранить экран заданной ширины и высоты как массив пикселей;
- считать `0` пустым пикселем, а ненулевые значения — цветами;
- выводить экран в консоль, не отображая нулевые пиксели;
- очищать экран;
- реализовать отрисовку отрезка между двумя точками по алгоритму Брезенхема;
- реализовать отрисовку треугольника как трёх отрезков по его вершинам;
- реализовать заливку области по алгоритму FloodFill:
  - 4-связную заливку;
  - 8-связную заливку — дополнительно, на дополнительный балл;
- заливка должна начинаться из заданной точки и заменять цвет связной области на новый;
- для заливки использовать стек, чтобы избежать переполнения стека вызовов при рекурсивном варианте;
- предоставить интерактивное меню команд для рисования, заливки, очистки и вывода экрана.

Поддерживаемые команды:

```
1 - clear 
2 x1 y1 x2 y2 color - make line with color 
3 x1 y1 x2 y2 x3 y3 color - make triangle circuit with color 
4 x y color - fill with color. 4-Flood fill algorithm. 
5 x y color - fill with color. 8-Flood fill algorithm. 
6 - print screen 
7 - exit 
```
# Краткое описание алгоритмов

## Отрисовка отрезка по алгоритму Брезенхема

Отрезок строится между двумя точками p1(x1, y1) и p2(x2, y2).

В программе используется целочисленный вариант алгоритма Брезенхема:

вычисляются dx = |x2 - x1|, dy = |y2 - y1|;

определяются направления шага sx и sy по осям x и y;

начальное значение ошибки: err = dx - dy;

сначала закрашивается точка p1;

пока текущая точка не совпала с p2, на каждом шаге:

вычисляется err2 = 2 * err;

если err2 >= -dy, то err -= dy, а x меняется на sx;

если err2 <= dx, то err += dx, а y меняется на sy;

после изменения координат текущий пиксель закрашивается заданным цветом.

Такой подход не использует вещественную арифметику и позволяет рисовать отрезок включительно от начальной до конечной точки. Треугольник в программе строится как три отрезка между его вершинами.

## Заливка области FloodFill

Заливка начинается из заданной точки start(x, y).

Сначала сохраняется исходный цвет пикселя:

curcolor = getPixel(screen, start);

Если исходный цвет уже равен новому цвету заливки, алгоритм сразу завершается.

Далее используется стек, в который кладётся начальная точка. Пока стек не пуст:

Из стека извлекается очередная точка.

Если цвет этой точки уже не равен curcolor, она пропускается — значит, она уже была закрашена или изначально не принадлежала области.

Иначе точка закрашивается новым цветом.

В стек добавляются соседние точки, если они не выходят за границы экрана.

Для FloodFill4 рассматриваются 4 соседа:
```
(x + 1, y)
(x - 1, y)
(x, y + 1)
(x, y - 1)
```
Для FloodFill8 дополнительно рассматриваются 4 диагональных соседа:
```
(x + 1, y + 1)
(x - 1, y + 1)
(x + 1, y - 1)
(x - 1, y - 1)
```
Использование собственного стека вместо рекурсии позволяет избежать переполнения стека вызовов при заливке больших областей.
