# algem_lab_1

На доп балл сделана реализация FloodFill8 и код написан на C.

## Постановка задачи

Реализовать консольное приложение на языке C — простой графический редактор, который работает с экраном как с двумерным массивом пикселей.

Требуется:

- хранить экран заданной ширины и высоты как массив пикселей;
- считать `0` пустым пикселем, а ненулевые значения — цветами;
- выводить экран в консоль, не отображая нулевые пиксели;
- очищать экран;
- реализовать отрисовку отрезка между двумя точками по алгоритму Брезенхема;
- реализовать отрисовку треугольника как трёх отрезков по его вершинам;
- реализовать заливку области по алгоритму FloodFill:
  - 4-связную заливку;
  - 8-связную заливку — дополнительно, на дополнительный балл;
- заливка должна начинаться из заданной точки и заменять цвет связной области на новый;
- для заливки использовать стек, чтобы избежать переполнения стека вызовов при рекурсивном варианте;
- предоставить интерактивное меню команд для рисования, заливки, очистки и вывода экрана.

Поддерживаемые команды:

```text
1 - clear 
2 x1 y1 x2 y2 color - make line with color 
3 x1 y1 x2 y2 x3 y3 color - make triangle circuit with color 
4 x y color - fill with color. 4-Flood fill algorithm. 
5 x y color - fill with color. 8-Flood fill algorithm. 
6 - print screen 
7 - exit
```
